# Student Performance Analysis

## Project Overview

This project analyses students' mathematics, reading, and writing scores using Microsoft Excel. The aim is to explore overall academic performance and examine differences associated with test preparation status.

## Tools Used

* Microsoft Excel
* PivotTables
* Charts and data visualization
* Excel formulas for data quality checks

## Data Quality Checks

The analysis includes checks for:

* Missing values
* Scores outside the expected range of 0–100
* Duplicate records

## Key Findings

* Average mathematics score: 66.09
* Average reading score: 69.17
* Average writing score: 68.05
* Students who completed the test preparation course had higher average scores in all three subjects than students who did not.
* The largest difference between the two groups was in writing, at 9.91 points.

## Limitations

The results describe the dataset and do not establish that test preparation caused higher scores. The findings should not be generalized to all students or schools. The dataset's reuse terms should be checked before redistributing the data.
